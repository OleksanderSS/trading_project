## 🔴 КРИТИЧНІ ПРОБЛЕМИ (Потребують негайного виправлення)

### 1. Batch Name Generation - Подвійні префікси

**Файл**: `src/pipeline/hybrid_orchestrator.py`, лінія ~300  
**Проблема**: Batch name генерується з подвійними префіксами

```python
# ❌ НЕПРАВИЛЬНО
batch_name = f"test_ticker_{test_ticker}_target_{test_target}_ep{epochs}_iter{max_iterations}"
# Результат: test_ticker_amd_target_target_return_1d_ep5_iter5
#                                 ^^^^^^ подвійний префікс!
```

**Наслідок**: Неправильні шляхи до файлів, помилки при завантаженні результатів

**Рішення**:
```python
# ✅ ПРАВИЛЬНО
batch_name = f"test_ticker_{test_ticker}_target_{test_target}_ep{epochs}_iter{max_iterations}"
# Результат: test_ticker_amd_target_return_1d_ep5_iter5
```

### 2. Картезіанський добуток при Merge Features + Targets

**Файл**: `src/pipeline/stages/stage_3_feature_engineering.py`  
**Проблема**: Merge без явного ключа може спричинити експоненціальне зростання рядків

```python
# ❌ НЕПРАВИЛЬНО
merged = features_df.merge(targets_df)  # Без ключа!
# Якщо features_df має 2520 рядків, targets_df має 2520 рядків
# Результат: 2520 * 2520 = 6,350,400 рядків!
```

**Наслідок**: Пам'ять переповнюється, тренування зависає

**Рішення**:
```python
# ✅ ПРАВИЛЬНО
merged = features_df.merge(targets_df, on=['ticker', 'timestamp'], how='inner')
# Результат: 2520 рядків (правильно)
```

### 3. Масштабування Y-значень для нейронних мереж

**Файл**: `colab_clean_cell.py`, лінія 555-646  
**Проблема**: Y масштабується, але inverse_transform робиться неправильно

```python
# ❌ НЕПРАВИЛЬНО
y_scaler = StandardScaler()
y_scaler.fit(y_tr.reshape(-1, 1))
y_pred_denorm = y_scaler.inverse_transform(y_pred.reshape(-1, 1))
# Проблема: y_scaler тренується на train set, але використовується для всіх даних!
```

**Наслідок**: Прогнози денормалізуються неправильно, метрики спотворені

**Рішення**: Зберегти y_scaler та використовувати його для всіх прогнозів

### 7. Ненадійна хеш-порівняння для дублікатів

**Файл**: `src/data/management/data_manager.py`  
**Проблема**: Хеш-порівняння case-sensitive, може не виявити дублікати

**Наслідок**: Дублікати не виявляються

**Рішення**: Нормалізувати дані перед хешуванням

### 9. Глобальна змінна в UnifiedConfigManager

**Файл**: `src/config/unified_config_manager.py`  
**Проблема**: Глобальна змінна `_config_instance` може спричинити проблеми в багатопотоковому середовищі

```python
# ❌ НЕПРАВИЛЬНО
_config_instance = None

def get_instance():
    global _config_instance
    if _config_instance is None:
        _config_instance = UnifiedConfigManager()
    return _config_instance
# Не thread-safe!
```

**Наслідок**: Race conditions у багатопотоковому коді

**Рішення**: Використовувати thread-safe singleton або dependency injection
