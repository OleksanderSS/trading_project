# Pattern Memory Update Policy

Pattern memory can be updated only after evidence and outcome review.

## Candidate update sources

- confirmed or partially confirmed hypothesis;
- falsified hypothesis with clear root cause;
- incident report;
- analyst debate packet;
- repeated evidence gap;
- repeated expectation gap miss;
- repeated wrong baseline basket;
- repeated wrong archetype tag.

## Approval levels

- automatic candidate creation: allowed;
- automatic production pattern update: forbidden;
- human-reviewed pattern promotion: required;
- eval regression test for major pattern update: required.

## Correct update examples

```text
Future green policy hypotheses require subsidy disbursement evidence, not only law passage.
```

```text
In crowded narratives, positive news can still produce weak response if priced probability was already high.
```

```text
Pre-1970 analogs should calibrate crisis regime language, not sector-specific outcome weights.
```
