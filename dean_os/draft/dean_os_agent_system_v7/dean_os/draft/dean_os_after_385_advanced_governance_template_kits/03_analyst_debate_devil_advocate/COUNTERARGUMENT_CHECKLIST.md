# Counterargument Checklist

For each major hypothesis, ask:

1. What if the event is already priced?
2. What if the control/baseline sector is contaminated?
3. What if this is a regime-changing event and analogs are weak?
4. What if the narrative is old/crowded?
5. What if the causal graph misses a counterforce?
6. What if source quality is weak?
7. What if the outcome metric is lagging?
8. What if market reaction is due to rates, liquidity, or broad risk-off?
9. What would falsify the hypothesis?
10. What evidence would make us reduce confidence?
