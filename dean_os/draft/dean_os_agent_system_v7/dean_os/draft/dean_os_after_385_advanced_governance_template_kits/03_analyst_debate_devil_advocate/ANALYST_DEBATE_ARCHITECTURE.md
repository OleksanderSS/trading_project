# Analyst Debate / Devil's Advocate Architecture

Purpose: prevent first-hypothesis lock-in and overconfident narrative formation.

For important events, DEAN-OS should create structured disagreement:

```text
Bull case analyst
Bear case analyst
Neutral reviewer
Evidence judge
Consensus/review packet
```

This is especially useful for:

- laws/policy shocks;
- regime-changing events;
- crowded narratives;
- earnings shocks;
- geopolitical events;
- technology bubbles;
- sector rotations.

## Rule

The debate produces review packets, not trading orders.
