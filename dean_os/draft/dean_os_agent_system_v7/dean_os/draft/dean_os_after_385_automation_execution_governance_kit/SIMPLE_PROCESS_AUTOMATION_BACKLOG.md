# Simple Process Automation Backlog

## Start here

1. Daily source collection run
2. Raw source copy + source hash
3. Dedupe + cluster decision
4. Metadata normalization: publication date, event date, ingestion date
5. Data quality + freshness checks
6. Normalized event packet creation
7. Analyst/domain routing
8. Risk archetype + expectation gap tags
9. Hypothesis/evidence gap creation
10. Daily digest
11. Daily audit log
12. Review queue

## Do not start here

- direct broker integration;
- direct live orders;
- LLM-generated buy/sell/hold;
- production model promotion without gates;
- autonomous config mutation.
