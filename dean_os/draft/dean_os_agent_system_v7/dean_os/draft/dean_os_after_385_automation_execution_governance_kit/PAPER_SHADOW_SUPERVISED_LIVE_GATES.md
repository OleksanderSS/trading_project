# Paper / Shadow / Supervised Live Gates

## Paper trading

- simulated broker only;
- live data allowed;
- real orders forbidden;
- risk engine active;
- kill switch tested;
- order lineage logged.

## Shadow live

- hypothetical live orders;
- broker send disabled and verified;
- slippage tracking;
- risk breach simulation;
- daily shadow report.

## Supervised live

- small capital;
- allowed assets only;
- allowed hours;
- human approval or emergency stop;
- max position / daily loss / drawdown active;
- unsupported assets blocked.
