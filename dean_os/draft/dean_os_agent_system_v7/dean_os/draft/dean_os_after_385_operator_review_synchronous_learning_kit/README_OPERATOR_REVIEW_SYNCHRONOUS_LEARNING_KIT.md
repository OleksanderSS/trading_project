# DEAN-OS After 385 — Operator Review / Synchronous Learning Kit

Non-numbered practical Codex-facing kit.

Purpose: define a review workflow where the operator receives reports while the agent also analyzes,
and the parallel human-agent experience becomes structured learning data.

This is not only approve/reject. It is synchronous co-analysis:

```text
agent report
→ operator review/correction
→ structured feedback labels
→ corrected hypothesis/evidence/scenario records
→ eval/regression examples
→ pattern memory candidates
→ future agent improvement
```

## Core principle

Review is not a passive checkpoint. Review is a learning surface.

The agent should:

- produce a structured report;
- explain evidence and uncertainty;
- expose assumptions;
- show candidate risk archetypes;
- show expectation-gap logic;
- show evidence gaps;
- propose watch metrics;
- create review items.

The operator should be able to:

- correct wrong archetype;
- mark missing evidence;
- flag overclaim;
- adjust confidence label;
- mark bad baseline basket;
- add counterforces;
- reject unsupported scenario;
- approve candidate learning examples.

## Boundary

Allowed:
- reports;
- review labels;
- corrected analysis records;
- learning examples;
- eval/regression candidates;
- review queue decisions.

Forbidden by default:
- direct buy/sell/hold;
- price target;
- trade signal;
- broker/order action;
- bypassing risk gates.
