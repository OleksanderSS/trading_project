## Architectural target

DEAN-OS is not a signal bot.

It is a research/trading operating system with:

- data/news collectors;
- daily Pipeline Controller governance;
- domain/macro analyst agents;
- macro regime and historical hypothesis ledger;
- evidence graph and source grounding;
- synchronous operator review;
- memory governance;
- strategy/playbook governance;
- scenario stress testing;
- replay/paper/shadow/supervised/constrained execution path;
- risk engine and execution gateway boundaries.

## Absolute boundaries

- No LLM direct order.
- No buy/sell/hold from analyst output.
- No price targets from these templates.
- No broker order before execution gateway.
- No strategy promotion without gates.
- No production prompt/model/config mutation without versioning and approval.
- No open hypothesis treated as fact.
- No historical analog treated as deterministic prediction.
