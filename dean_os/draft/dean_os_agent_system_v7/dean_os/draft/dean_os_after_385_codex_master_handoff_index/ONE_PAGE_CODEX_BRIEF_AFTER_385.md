# One-Page Codex Brief After 385

## Goal

Turn the existing DEAN-OS pipeline into a governed agentic research/trading OS.

## Start here

1. Read `dean_os_after_385_full_context_bundle.zip`.
2. Read `dean_os_after_385_codex_integration_kit.zip`.
3. Use this master handoff index to navigate the remaining kits.

## First implementation target

Do not start with trading.

Start with:

```text
daily run manifest
→ source provenance
→ collector health
→ normalized event packet
→ tag-only analyst output
→ review report
→ feedback labels
→ eval/audit
```

## Why

The existing pipeline already has collectors, news impact logic, context analyzers, causal methods,
pipeline guards, evaluation stages, and trading/execution modules.

The missing layer is governance:

- who starts daily automation;
- how data becomes event packets;
- how analyst outputs are constrained;
- how review becomes learning;
- how memory is promoted;
- how strategies are gated;
- how stress tests block unsafe behavior.

## Never do first

- live broker integration;
- direct LLM trading;
- strategy promotion without replay/paper/shadow;
- production config mutation without gate;
- historical analog as deterministic prediction.
