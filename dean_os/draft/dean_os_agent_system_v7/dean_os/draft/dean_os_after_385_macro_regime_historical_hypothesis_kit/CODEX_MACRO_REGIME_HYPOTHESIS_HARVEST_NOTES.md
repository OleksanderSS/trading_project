Important interpretation rule:

Historical analogs are not predictions. They are structured comparison tools.

Use: similar mechanism, different regime; candidate analog; hypothesis; evidence required; partially confirmed; weakened; inconclusive.

Avoid: this is exactly like 1973; therefore same outcome; guaranteed result; trade signal.
