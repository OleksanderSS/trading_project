# DEAN-OS After 385 — Macro Regime / Historical Analog / Open Hypothesis Kit

Non-numbered practical kit after the closed after-385 staged bundle.

Purpose: preserve the design idea that DEAN-OS should analyze events, laws, crises, and news inside
long-run macro/historical regimes, create open hypothesis tokens for major events, track scenario paths,
and compare expected outcomes with reality.

Core model:

```text
event/news/law
→ macro regime snapshot
→ historical analog candidates
→ mechanism comparison
→ causal graph
→ scenario tree
→ evidence milestones
→ open hypothesis ledger
→ outcome review
→ lessons learned
```

Allowed outputs:
- historical context;
- scenario hypothesis;
- evidence gap;
- review queue item;
- internal digest;
- outcome review.

Forbidden outputs:
- buy/sell/hold;
- price target;
- trade signal;
- broker/order action;
- autonomous portfolio change;
- deterministic historical analogy;
- exact causality claim without evidence.

## v2 additions

This kit now captures these refinements:

- expectation gap: compare actual outcome vs market/priced expectation;
- regime-changing events: some events change the macro regime itself;
- reflexivity: market expectations and positioning can alter outcomes;
- narrative half-life: track narrative age, dominance, crowdedness, and reversal risk;
- historical priors: scenario probabilities should come from EventDatabase/base rates, market-implied data, or reviewed priors, not LLM probabilities alone;
- historical data usage boundary: pre-1970 history is mainly for regime calibration and broad mechanisms, not sector/company forecasts;
- validation circularity: outcome review should avoid measuring only targets that system actions could influence.

## v3 additions

This kit now also includes cross-check additions from Gemini-style critique:

- risk/macro archetypes instead of naive "similar year" matching;
- tag-only analyst output schema to prevent probability hallucination;
- cross-sectional baseline framework with contamination risk;
- data alignment/frequency handling across old and modern datasets;
- leading risk monitors for Pipeline Controller because PnL/train-test metrics lag regime shifts;
- decision lineage schema for debugging multi-agent outputs.
