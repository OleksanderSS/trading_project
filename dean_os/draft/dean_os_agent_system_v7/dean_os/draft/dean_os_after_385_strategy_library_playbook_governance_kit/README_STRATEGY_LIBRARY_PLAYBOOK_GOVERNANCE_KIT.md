# DEAN-OS After 385 — Strategy Library / Playbook Governance Kit

Non-numbered practical Codex-facing kit.

Purpose: define governance for a future strategy/playbook library before replay, paper, shadow,
supervised live, or constrained autonomous execution.

This kit does not create trading signals. It defines how strategies are registered, versioned,
evaluated, gated, blocked, reviewed, and linked to regimes, risk limits, and execution maturity.

## Core principle

```text
A strategy is not allowed because it exists.
A strategy is allowed only in specific regimes, assets, modes, risk budgets, and validation states.
```

## Relationship to other kits

- Macro Regime Kit v3 defines regimes, archetypes, expectation gaps, and hypothesis tokens.
- Automation / Execution Governance Kit v2 defines replay/paper/shadow/supervised/constrained gates.
- Eval / Observability / Audit Kit defines quality tests.
- Advanced Governance Kit defines portfolio/capital governance.
- Agent Memory Kit defines how learned lessons become approved patterns.
- Operator Review Kit defines human-agent review and learning.

## Boundary

Allowed:
- strategy registry;
- playbook definitions;
- regime compatibility;
- allowed/forbidden inputs;
- validation requirements;
- risk constraints;
- promotion gates;
- review packets.

Forbidden by default:
- direct buy/sell/hold;
- price target;
- broker order;
- LLM direct order;
- bypassing risk engine;
- live execution without maturity gates.
