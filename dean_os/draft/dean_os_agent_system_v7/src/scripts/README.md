# 📋 Скрипти системи (System Maintenance & Automation Toolkit)

Ця директорія містить набір автономних інструментів для обслуговування, автоматизації та оптимізації компонентів системи. Скрипти забезпечують "здоров'я" даних та моделей, працюючи як допоміжні сервіси для основного пайплайну.

## 📂 Категорії та призначення:

### 1. Робота з даними (`data/`)
*   **`auto_accumulator.py`**: Монітор доступності даних (Data availability monitor). Автоматично дозавантажує пропуски в історії, забезпечуючи безперервність "фундаменту" для **Stage 1**.

### 2. Аналіз та правила (`analysis/`)
*   **`generate_context_rules.py`**: Генератор правил ринкових режимів. Аналізує статистичні зв'язки та створює `generated_context_rules.yaml` для **Stage 2** (Market Context).

### 3. Моделювання та оптимізація (`modeling/`)
*   **`train_consensus_model.py`**: **Тренер мета-моделі для ConsensusEngine**. Цей скрипт навчає модель `StackedEnsemble` на історичних прогнозах, щоб знайти оптимальні ваги для їх комбінування. Результат (навчена модель) зберігається і використовується **Stage 5** для прийняття фінального рішення.

### 4. Моніторинг системи (`monitoring/`)
*   **`run_health_check.py`**: Запускає комплексну перевірку "здоров'я" системи за допомогою `HealthHub`. Цей скрипт надає звіт про стан ресурсів (CPU, пам'ять, диск), прогнозує ризики збоїв за допомогою ML-моделей та виявляє аномалії в поведінці системи. Це ключовий інструмент для забезпечення стабільності та надійності роботи всього комплексу.
