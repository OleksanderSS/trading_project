# Архітектура модуля звітності та аналітики ('''src/reporting''')

Цей модуль містить ключові компоненти для аналізу ринкових даних, сигналів та контексту, а також для генерації звітів. Він побудований на основі принципу єдиного аналітичного движка, що дозволяє гнучко додавати та комбінувати різні аналітичні модулі.

### Ключові компоненти:

1.  **`unified_analytics_engine.py`**: Ядро модуля. Цей клас (`UnifiedAnalyticsEngine`) відповідає за реєстрацію та паралельне виконання всіх аналітичних компонентів. Він використовує пул потоків для ефективної обробки даних.

2.  **`interfaces.py`**: **(НОВЕ)** Цей файл містить абстрактні базові класи (`IAnalyzer`, `IComparator`, `IContextProcessor`), що визначають контракти для всіх аналітичних модулів. Це забезпечує слабку зв'''язаність та високу розширюваність системи.
