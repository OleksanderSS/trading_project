# Утиліти (`src/utils`)

Ця директорія містить набір допоміжних класів та функцій, які використовуються в усьому проєкті. Це фундаментальні інструменти, що забезпечують динамічне завантаження, керування конфігураціями, обмеження швидкості та роботу з торговим календарем.

### Ключові компоненти:

- **`dynamic_module_loader.py`**: Критично важлива утиліта, що реалізує інверсію контролю. Вона дозволяє динамічно завантажувати класи на основі рядкових шляхів з YAML-конфігурацій. Це робить систему гнучкою, дозволяючи змінювати компоненти без модифікації коду.

- **`rate_limiter.py`**: Реалізує потоко- та асинхронно-безпечний алгоритм "Token Bucket". Цей клас централізовано використовується в `HttpClientFactory` для глобального обмеження кількості HTTP-запитів до зовнішніх API, що є життєво важливим для стабільності збирачів даних.

- **`trading_calendar.py`**: Надає доступ до торгового календаря NYSE через бібліотеку `trading_calendars`. Утиліта дозволяє визначати торгові дні, години та виконувати розрахунки, пов'язані з ринковими даними, що є необхідним для коректної роботи пайплайнів обробки та валідації.

- **`json_utils.py`**: Стандартизовані утиліти для надійної роботи з JSON, забезпечуючи консистентну серіалізацію та десеріалізацію в усьому проєкті.

- **`notebook_generator.py`**: Інструмент для автоматизації створення Jupyter Notebooks з результатами аналізу, що спрощує подальші дослідження та візуалізацію.

### Роль в системі

Папка `utils` служить як "набір інструментів" проєкту. Централізація загальних завдань, таких як динамічне завантаження, обмеження швидкості та робота з календарем, сприяє повторному використанню коду, зменшує дублювання та підтримує чіткий поділ між бізнес-логікою та інфраструктурною підтримкою.
