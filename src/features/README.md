# ⚙️ Модуль Генерації Фіч (Features)

Цей модуль є центральним компонентом для створення, збагачення та відбору фіч (ознак), які використовуються для тренування моделей машинного навчання.

### Архітектура

Архітектура модуля побудована навколо двох ключових концепцій:

1.  **Збагачувачі (Enrichers)**: Це незалежні, модульні класи, кожен з яких відповідає за додавання певної групи фіч до датасету. Всі збагачувачі наслідують єдиний інтерфейс `BaseEnricher` (`src/features/enrichers/base.py`), що гарантує їхню сумісність.

2.  **Оркестратор (Orchestrator)**: Клас `FeatureOrchestrator` (`src/features/feature_orchestrator.py`) керує всім процесом. Він читає конфігурацію, динамічно завантажує та ініціалізує **ввімкнені** збагачувачі, а потім послідовно застосовує їх до даних. Це дозволяє гнучко керувати набором фіч через конфігураційні файли, не змінюючи код.

### Підмодулі

*   **`/enrichers`**: Містить реалізації всіх збагачувачів (технічний аналіз, макроекономіка, фічі часу тощо).
*   **`/nlp`**: Великий підмодуль для обробки природної мови, який використовується для генерації фіч з новин та текстових даних.
*   **`/selection`**: Містить логіку для "розумного" відбору фіч після їх генерації.
*   **`/scoring`**: Компоненти для проміжного оцінювання, наприклад, розрахунку скорингу новин.

### Потік Роботи

1.  `FeatureOrchestrator` створюється на основі конфігурації.
2.  Оркестратор запускає ланцюжок ввімкнених збагачувачів, кожен з яких додає свої стовпці до DataFrame.
3.  (Опціонально) Після збагачення запускається `SmartFeatureSelector` для відбору найбільш значущих фіч.
4.  Фінальний, збагачений та відібраний датасет повертається для подальшого використання в пайплайні (тренування або прогнозування).
