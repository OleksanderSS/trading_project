# 🛠️ Інструменти розробника (devtools)

Ця директорія містить інструменти, фреймворки та утиліти, які допомагають у розробці, тестуванні та аналізі, але **не є частиною основного виробничого (production) пайплайну**.

### Призначення

Мета цього модуля — відокремити код, що підтримує розробку, від коду, що виконує основну бізнес-логіку.

### Компоненти:

*   **`/experimentation`**: Містить базовий фреймворк для проведення структурованих експериментів, порівняння моделей та генерації візуалізацій. Це дозволяє дослідникам тестувати гіпотези в ізольованому середовищі.
*   **`/monitoring`**: (Потенційно) Інструменти для моніторингу стану системи, продуктивності моделей тощо.
*   **`/profiling`**: (Потенційно) Скрипти для аналізу продуктивності та вузьких місць у коді.
