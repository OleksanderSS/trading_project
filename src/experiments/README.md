# 🧪 Експерименти (experiments)

Ця директорія слугує **пісочницею** для швидкої перевірки гіпотез, запуску одноразових скриптів та початкового аналізу даних.

### Призначення

На відміну від структурованого фреймворку в `devtools/experimentation`, код у цій папці може бути менш формалізованим. Він призначений для швидких ітерацій та досліджень, результати яких згодом можуть бути перенесені в більш стабільні частини системи.

### Приклади використання:

*   Аналіз нового джерела даних.
*   Тестування простої торгової ідеї.
*   Написання скрипту для одноразової трансформації даних.

**Примітка**: Весь основний, багаторазово використовуваний інструментарій для проведення експериментів було перенесено до `devtools/experimentation`.
