# Pipeline Stage Runners

Скрипти для поетапного запуску пайплайну з аналізом результатів кожного етапу.

## Структура Пайплайну

Пайплайн складається з 8 етапів, згрупованих в 4 фази:

### Фаза 1: Data Generation & Collection (Етапи 0-1)
- **Stage 0:** Data Generation - Генерація синтетичних даних
- **Stage 1:** Collection - Збір даних з різних джерел

### Фаза 2: Processing & Feature Engineering (Етапи 2-3)
- **Stage 2:** Processing - Очистка та нормалізація даних
- **Stage 3:** Feature Engineering - Створення фіч та таргетів

### Фаза 3: Modeling & Prediction (Етапи 4-5)
- **Stage 4:** Modeling - Тренування ML моделей
- **Stage 5:** Prediction - Генерація прогнозів

### Фаза 4: Trading Execution & Evaluation (Етапи 6-7)
- **Stage 6:** Trading Execution - Виконання торгів
- **Stage 7:** Evaluation - Оцінка стратегії та бектестинг

## Скрипти

### 1. `run_stage_0_1.py`
Запускає етапи 0 та 1 з аналізом результатів.

```bash
python scripts/run_stage_0_1.py
```

**Перевіряє:**
- Статус виконання Stage 0
- Генерація фіч та таргетів
- Кількість даних
- Статус виконання Stage 1
- Збір даних з джерел
- Наявність даних

### 2. `run_stage_2_3.py`
Запускає етапи 2 та 3 з аналізом результатів.

```bash
python scripts/run_stage_2_3.py
```

**Перевіряє:**
- Статус виконання Stage 2
- Обробка даних
- Наявність оброблених даних
- Відсутність NaN значень
- Статус виконання Stage 3
- Наявність фіч та таргетів
- Вирівнювання фіч та таргетів

### 3. `run_stage_4_5.py`
Запускає етапи 4 та 5 з аналізом результатів.

```bash
python scripts/run_stage_4_5.py
```

**Перевіряє:**
- Статус виконання Stage 4
- Тренування моделей
- Метрики продуктивності моделей
- Вибір найкращої моделі
- Статус виконання Stage 5
- Наявність прогнозів
- Оцінки впевненості
- Ансамбль прогнозів

### 4. `run_stage_6_7.py`
Запускає етапи 6 та 7 з аналізом результатів.

```bash
python scripts/run_stage_6_7.py
```

**Перевіряє:**
- Статус виконання Stage 6
- Виконання торгів
- Оновлення портфеля
- Розрахунок ризик-метрик
- Статус виконання Stage 7
- Результати бектестингу
- Метрики продуктивності
- Генерація звітів та візуалізацій

### 5. `run_full_pipeline.py`
Запускає повний пайплайн послідовно з аналізом після кожної фази.

```bash
python scripts/run_full_pipeline.py
```

**Запускає:**
1. Фаза 1 (Stage 0-1)
2. Фаза 2 (Stage 2-3)
3. Фаза 3 (Stage 4-5)
4. Фаза 4 (Stage 6-7)

Зупиняється, якщо будь-яка фаза не пройде перевірку.

## Результати

Результати зберігаються в `data/stage_results/`:

- `stage_0_1_results.json` - Результати етапів 0-1
- `stage_2_3_results.json` - Результати етапів 2-3
- `stage_4_5_results.json` - Результати етапів 4-5
- `stage_6_7_results.json` - Результати етапів 6-7
- `full_pipeline_summary.json` - Підсумок повного запуску

## Аналіз Результатів

Кожен скрипт виконує детальний аналіз:

### Перевірки (Checks)
- ✅ **Passed** - Перевірка пройшла успішно
- ❌ **Failed** - Перевірка не пройшла

### Категорії Перевірок
- **Статус виконання** - Чи етап виконався успішно
- **Наявність даних** - Чи дані існують і не пусті
- **Якість даних** - Відсутність NaN, вирівнювання розмірів
- **Повнота** - Чи всі компоненти присутні

### Приклад Виводу

```
📊 Stage 0 Analysis:
   Status: SUCCESS
   Overall Passed: True
   ✅ Stage status: Stage succeeded
   ✅ Data points generated: Generated 1000 data points
   ✅ Features DataFrame exists: Features shape: (1000, 50)
   ✅ Targets DataFrame exists: Targets shape: (1000, 5)
```

## Використання

### Поетапний Запуск
Запускайте скрипти послідовно для детального аналізу кожної фази:

```bash
python scripts/run_stage_0_1.py
# Перевірте результати
python scripts/run_stage_2_3.py
# Перевірте результати
python scripts/run_stage_4_5.py
# Перевірте результати
python scripts/run_stage_6_7.py
# Перевірте результати
```

### Повний Запуск
Запустіть повний пайплайн для автоматичного виконання всіх фаз:

```bash
python scripts/run_full_pipeline.py
```

## Переваги

1. **Детальний аналіз** - Кожен етап перевіряється на правильність
2. **Раннє виявлення проблем** - Проблеми виявляються на ранніх етапах
3. **Повнота перевірка** - Перевіряється, чи все залучено
4. **Збереження результатів** - Всі результати зберігаються для аналізу
5. **Зупинення при помилках** - Пайплайн зупиняється при критичних помилках

## Налаштування

Скрипти використовують конфігурацію з `src/config/unified_config_manager.py`.

Для зміни параметрів:
1. Відредагуйте конфігураційний файл
2. Перезапустіть скрипти

## Вирішення Проблем

### Помилка: Previous results not found
**Рішення:** Запустіть попередній скрипт перед переходом до наступного.

### Помилка: Stage failed
**Рішення:** Перевірте логи та результати в JSON файлі для детальної інформації.

### Помилка: No data
**Рішення:** Перевірте конфігурацію та джерела даних.
